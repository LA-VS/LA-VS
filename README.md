The projects below began as apprenticeship coursework. I rebuilt each one to a professional standard: one clear question, data fetched or generated by script, tested code, and a README that leads with the answer.

### How I work

1. **Question.** Agree one question and what a useful answer looks like before touching the data.
2. **Data.** Find the source, record where it came from, and fetch it by script so it can be fetched again.
3. **Clean.** Profile first, then write the fixes as tested rules, so every change is repeatable and logged.
4. **Model.** Start with a baseline, then use the simplest method that answers the question, and check its assumptions.
5. **Communicate.** Lead with the answer as a number and one chart, then the method and the limits.
6. **Review.** Check the result with the people who will use it, and note what to do differently next time.
